# Windows 人工验收方案（2026-11-13）

本轮验收先确认默认手动布局库与可选后台挂载，再确认通知和恢复逻辑。自动检查通过不等于系统横幅、界面外观或真实屏幕硬件验收通过。

## 1. 启动与现场备份

1. 退出旧版 DeskFrzA，避免两个版本同时执行保护。此前默认驻留的旧测试实例需要从托盘右键“退出”；本次新版仅在开启后台时 X 隐藏，关闭后台时 X 真正退出。
2. 在仓库根目录执行下方的构建和启动命令。验收实例使用独立记录目录 `artifacts/acceptance-20261113`，不替换已安装版本，不修改正式记录库。
3. **独立记录库仍操作真实桌面。** 可直接保存当前现场并命名“验收前备份”，不需要先设置默认单屏模板。连接双屏后，再保存“双屏验收前”。截图保留位置和显示设置。若测试库已有默认单屏项，以后台开启状态重启可能按该项自动恢复；先确认默认项是希望保护的布局。
4. 前几项保持主屏、分辨率、缩放、图标大小及“对齐到网格”不变，桌面的“自动排列”保持关闭。到专门的网格/屏幕测试再调整这些设置。
5. 设置中关闭测试实例的自动更新，测试过程中不安装更新。

在已安装 .NET 8 SDK 的 PowerShell 中执行以下命令：

```powershell
dotnet build DeskFrz/DeskFrz.csproj -c Release -o artifacts/acceptance-build-notifications
if ($LASTEXITCODE -ne 0) { throw '验收构建失败' }
& .\artifacts\acceptance-build-notifications\DeskFrzA.exe --data (Join-Path $PWD 'artifacts\acceptance-20261113')
```

## 2. 使用模式与通知（优先验收）

| 编号 | 操作 | 通过标准 |
| --- | --- | --- |
| M1 默认与外观 | 首次启动新库或没有后台设置的旧库；查看 GitHub 左侧小开关，悬停及用 Tab 聚焦 | 默认关闭、没有可见文字标签；面板显示“是否开启后台挂载：当前为否”，字体与应用一致，配色与圆角自然；不弹强制单屏初始化 |
| M2 默认关闭行为 | 保持开关关闭，直接保存单屏/双屏记录；点窗口 X | 均可直接保存，保存单屏不自动设为默认；X 后程序退出、无托盘驻留、本地服务停止；不会自动恢复默认模板 |
| M3 开启并记忆 | 打开开关，悬停；从托盘“退出”，再用同一入口启动 | 文案变为“当前为是”，选择记忆；重新启动仍开启，记录、间距、更新设置保持 |
| M4 系统提醒 | 开启后先从托盘右键“发送测试通知”，再 X 隐藏，拖动一个图标并停止，等约2–6秒 | 测试横幅出现且不唤回应用；真实变化的系统横幅询问是否保存，托盘加静态橙点、悬停说明待处理。稳定同一现场不会每两秒提醒一次；连续变动有10秒节流，拖动中间位置不逐帧提醒 |
| M5 处理提醒 | 点击横幅，分别试“暂不保存”和“保存为新记录” | 只有点击后才打开应用确认；关闭横幅、超时不保存。确认保存后状态一致且不再次误报；若横幅没显示，可从托盘“查看桌面改动”处理 |
| M6 弹窗与类型 | 打开设置/重命名弹窗时触发改动提醒，点击通知，再关闭原弹窗；处理过切屏提醒后再触发普通图标改动 | 原弹窗输入不被覆盖；关闭后进入本次保存确认；普通图标提醒不重新进入旧切屏流程 |
| M7 关闭并记忆 | 关闭开关后悬停，X 退出，再启动 | 文案为“当前为否”，无驻留；重启仍关闭，先前记录保留；其他设置保存不会反向修改此选择 |

通知采用已注册应用身份的Windows Toast，正文点击后在应用确认，不在横幅中直接放保存按钮。托盘右键显示“已提交 / 已被Windows禁用 / 发送失败”等状态。未看到横幅时先记录这行状态及系统“通知/免打扰”设置；不能把“已提交”当作展示通过。最近诊断在测试数据目录的 `notification-status.json`。测试通知只打开窗口，不制造保存请求；处理真实改动后橙点应消失。关闭后台或退出后，通知清除，旧通知不能启动正式库或执行恢复。新通知依赖的最低系统为Windows 10 1809或Windows 11。

## 3. 开启后台时的系统托盘与窗口

以下 T 项先将开关设为开启。

| 编号 | 操作 | 通过标准 |
| --- | --- | --- |
| T1 | 点击窗口右上角 X，展开任务栏右下角的小箭头 | 主窗口隐藏、任务栏窗口消失；通知区域能找到 DeskFrzA 图标。图标是否位于折叠区由 Windows 的托盘设置决定 |
| T2 | 双击托盘图标，再次关闭；右键托盘选择“打开 DeskFrzA” | 两种方式均唤回原窗口，记录和界面可用，没有新增实例 |
| T3 | 隐藏到托盘后，再执行同一条启动命令；窗口最小化时再试一次 | 唤回现有窗口，最小化窗口恢复显示，不创建第二个同记录库实例 |
| T4 | 托盘右键选择“退出”，随后再次运行启动脚本 | 旧进程和本地服务结束、托盘图标移除；重新启动正常，记录保留 |
| T5 | 自行选择默认单屏项后，隐藏到托盘并执行下表 R6 的接屏/拔屏流程 | 后台恢复继续生效；主屏切换只发系统提醒，不主动唤回窗口，点击提醒后才处理 |
| T6 | 先退出旧测试实例；用新版打开任务管理器，记录主程序及所属 WebView2 子进程内存。隐藏到托盘，等待 10 秒，再打开；重复 10 次并驻留 10 分钟 | 持续隐藏/最小化两秒后开始释放界面，所属 WebView2 子进程应退出，后台内存明显回落；重开后页面、记录和撤销可用；稳定隐藏时不应每轮持续大幅增长。记录实际数值，不把其他应用的 WebView2 一并统计 |

隐藏不等于开机自启动；本轮未增加开机启动设置。完全退出后无法继续监测桌面。

内存按“主程序 + 该实例的子进程”统计，分别记录私有内存与工作集；工作集合计含共享页，不能当成独占物理内存。当前方案释放网页后，重开会重新读取后台状态；未提交的弹窗输入、当前预览和页面展开/滚动状态会重置，已保存记录和恢复备份保留。快速关闭后两秒内重开可复用原页面。

## 4. 桌面恢复

数量不必恰好为 50 和 70。以现有 N 个图标为基准，新增 20 个临时快捷方式模拟 N→N+20；不用删除个人文件。快捷方式保持原名和原目标，避免把重命名当作数量变化。

| 编号 | 操作 | 通过标准 |
| --- | --- | --- |
| R1 数量变化 | 单屏下保存布局 A；新增 20 个临时快捷方式并挪动几个原图标，保存 B；A、B 交替恢复至少 5 次，每次成功后等待 10 秒 | 始终保留 N+20 个图标；A/B 的原图标回到对应位置；额外图标无冲突时保留，冲突时同屏避让；显示“布局一致”，没有刚恢复就要求保存新记录 |
| R2 单屏模板作用域 | 保留单屏 A；接副屏，把额外快捷方式放在副屏；再把 A 内一个图标移到副屏。保存“双屏验收前”，然后恢复 A | A 内图标回到原目标屏；副屏上的无关快捷方式保持原位。普通恢复不因副屏成为主屏就自动把整组搬过去 |
| R3 撤销范围 | 接 R2，移动一个副屏上与回退位置无冲突的额外快捷方式，再点“撤销上次恢复”。保持网格开关不变 | R2 实际移动过的图标回到恢复前位置；后续手动移动的无关图标保持；撤销入口清除。若仍有独立手动改动，显示“布局有改动”属于正确结果 |
| R4 已有布局识别 | 在 B 保存时相同的单屏配置下恢复完整 B；移动一个图标，等待 10 秒；再拖回 B 中的原位置并等待 10 秒 | 移动后识别为改动；完整桌面回到 B 后识别已有 B，不要求新建记录。只回到 A 的部分图标、额外图标仍与 B 不同，不算完整匹配 |
| R5 网格确认与撤销 | 关闭网格，将两个图标自由摆放并保存单屏 F；接副屏、重新开启网格、改变这两个位置；恢复 F，再撤销 | 现有确认框明确提示关闭网格；确认后保存坐标正确；撤销恢复此前坐标及网格设置。网格是全局设置，重新开启时 Windows 可能吸附其他屏幕的图标 |
| R6 托盘后台自动恢复 | 开启后台；实际单屏下准备位置不同的 A、B，自行把 A 设为默认；接副屏、隐藏窗口，再拔副屏，等待约5–10秒；随后手动恢复 B，再等10秒 | 单屏稳定后自动恢复 A 一次；手动恢复 B 后保持 B。再移动图标不会反复被恢复覆盖；关闭后台时重复本项不应自动恢复 |
| R7 主屏切换与撤销 | 开启后台，双屏保存完整现场并隐藏；在 Windows 中切换主屏，点击系统提醒。若提示无法整体迁移，选择“撤销切换” | 发提醒时窗口不自行显示；点击后按条件恢复原配置和图标。失败给出原因并保留备份，不出现连续反向提示。图标集中在一屏时可能进入迁移预览 |
| R8 缩放适配 | 保存有明显空行/空列的布局，改变同屏缩放或分辨率，再预览、恢复；恢复显示设置后恢复验收前记录 | 原有分组、空行/空列按适配规则保留；不丢失图标，不发生未说明的跨屏移动；空间不足时明确阻止。混合 DPI、负坐标、副屏主屏分别记录 |
| R9 接回与短暂断开 | 备份现场后，接入副屏保持主屏不变；再尝试短暂断开后立即接回；另试单屏恢复等待期间继续移动图标 | 接回不自动恢复双屏历史或迁移；已读取到的短暂断开在返回多屏时取消单屏任务。持续单屏下需图标停止变化两秒才执行默认恢复；恢复后手动移动不再次覆盖 |

## 5. 结束、判定与问题记录
