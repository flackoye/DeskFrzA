# 恢复规则

记录中的“恢复布局”统一处理普通恢复和换屏迁移，不修改 Windows 主屏设置。

默认作为手动布局库使用：后台挂载关闭，保存及恢复都由用户操作，窗口 X 退出。开启右上角 GitHub 左侧开关后才监测变化和运行自动保护，选择即时持久保存；悬停说明“是否开启后台挂载：当前为否/是”。不强制初始化默认单屏模板，单屏、多屏都能直接保存。

| 情况 | 处理 |
| --- | --- |
| 屏幕及图标配置相同 | 按保存的位置恢复 |
| 同一批显示器的排列或主屏改变 | 普通恢复按设备身份匹配，图标跟随原屏幕 |
| 分辨率、缩放或图标尺寸改变 | 尽量保留原排列；普通恢复必要时重新排布 |
| 需要换屏且原图标集中在一屏 | 显示整体迁移预览，确认后执行 |
| 新增 / 删除图标 | 普通恢复保留新图标，处理位置冲突；跳过已删除项目 |
| 容量不足、设备身份不明或复制显示 | 暂停并提示原因 |

原显示器仍可匹配时优先普通恢复。网格开关、工作区域或间距报告变化不会把历史恢复自动改为迁移到当前主屏；原屏不可用或明确选择迁移时才进入迁移预览。

多屏历史若全部图标都在仍连接的一块屏幕上，断开当时未放图标的其他屏幕后，仍可在原屏恢复。记录确实包含已断开屏幕上的图标时，不做不完整的恢复。

双屏或多屏下恢复单屏模板，只恢复模板内仍存在的图标，并处理目标屏上的新增图标冲突。其他屏幕上的无关图标保留原位，也不会因那些屏幕的容量阻止目标屏恢复。模板内图标即使当前在其他屏幕，仍会归回目标屏。

迁移优先整体平移，保留间距和相对位置；放不下时预览等比例缩小。仍越界、重叠或与新增图标冲突时暂停。必要时会询问是否关闭“对齐到网格”；不会修改显示缩放或图标大小。

仅在后台挂载开启、用户已选定默认单屏模板时，只剩一块屏幕且配置和图标位置稳定两秒后自动恢复，每次稳定配置只执行一次。等待期间Windows继续调整图标或用户拖动图标时重新计时；成功或失败锁存后，后续拖动不重新触发自动恢复。开启开关本身不覆盖当前桌面。默认项只有一个；删除前需先更换默认项。保存单屏记录不会自动设为默认。单屏恢复同时恢复保存时的“对齐到网格”状态。想要规整排列，请开启网格对齐后重新整理、保存并设为默认；旧的自由摆放记录仍保留原设置。

插拔DP、HDMI或扩展坞统一按Windows实际报告的活动屏幕处理，不按接口名称猜测。多屏变单屏时，有默认单屏项才执行上述自动恢复；没有默认项就保留Windows处理后的现场。接回多屏不会自动选择或恢复某条多屏历史；主屏改变时仅保留最近观察到的切换前现场并发通知，整体迁移需用户确认。仅增加副屏、主屏不变时不触发主屏迁移；三屏变两屏也不走单屏默认恢复。自动单屏恢复始终使用明确指定的默认项，即使当前恰好匹配其他已存单屏记录也一样。

不足两秒的有效单屏瞬态若随后读到多屏，会取消待恢复；未成功捕获的瞬态不能保证识别。切屏现场在内存中，不能保证突然断开前最后一次拖动已经被读取；变成单屏或同主屏的屏幕组合变化会清掉旧的主屏切换提示。此功能不保存显示器物理连接状态，也不合并分散在多块屏幕上的历史图标。

手动保存或恢复成功会消费当前待执行的单屏自动恢复，避免稍后覆盖手动结果。改用另一默认项、重新接屏后拔出或点击“重新恢复”才重新启动等待；设置相同默认项不重复执行。

当前连接多屏、恢复坐标需要自由摆放时，现有确认弹窗会说明将关闭“对齐到网格”，确认后执行。撤销同时恢复此前的网格状态。网格是 Windows 桌面的全局设置；普通恢复不会打开自动排列。

后台挂载开启时可保留主屏切换前的现场。原显示器仍全部连接且持有切换前配置时，可撤销切换；关闭应用期间无法记录现场。图标改动和主屏切换只发 Windows 通知，不主动唤回窗口；点击通知后重新读取当前现场，再进入对应保存或切屏处理流程。通知未点击不会执行保存或恢复。

图标检测沿用两秒观察，稳定至少一秒后提醒；同一布局不重复提醒，连续变动最多十秒提醒一次。去重保留在原生进程，不随页面释放而重置。保存/恢复成功、回到完整已有记录时不产生额外的新记录通知。系统提醒采用注册的Windows Toast；待处理变化同时在托盘图标显示静态橙点，悬停说明有改动待处理。系统横幅可能被Windows通知或免打扰设置抑制；托盘右键“查看桌面改动”仍可处理，另有“发送测试通知”和提交状态便于排查。不会因横幅超时而自动保存。

恢复前保存备份，执行后核对图标位置。桌面在预览后发生变化时，需重新预览。失败保留备份，支持撤销。

成功操作的撤销只回退本次实际移动过的图标，并恢复此前网格设置，避免覆盖其他屏幕上后续的独立调整；回退位置发生冲突时仍会处理目标屏上的冲突图标。这个范围只约束应用安排的坐标移动，重新开启全局网格时，Windows 仍可能吸附其他屏幕的图标。旧版没有操作范围的撤销记录及失败操作的应急备份继续按完整桌面恢复。

成功后用完整实际桌面作为变化比较基准：70 个现有图标恢复 50 个图标的历史模板，额外图标仍保留，不会仅因数量不同立即询问保存新记录。之后手动移动原有或新增图标仍会显示改动。若完整桌面精确回到另一条已保存记录，会识别该记录；不会把只匹配部分图标的模板当作整个桌面。

新捕获会保存 Shell 视图的 Windows DPI，用于格距归一化模型，格距不再由图标数量或坐标公约数推算。旧记录继续保留；相同屏幕几何优先恢复物理坐标，缺少 DPI 元数据的旧记录在适配时先按显示比例换算物理间隔，再按当前网格安排。有效格距改变且原排列不再对齐时，会适配当前格点；不能从旧记录中唯一反推出当时的基础格距。该模型已在本机单屏核对，混合 DPI 的硬件组合仍需实机验收。

数据位置：`%LOCALAPPDATA%\DeskFrz\library.json`。设备路径可能随接口、扩展坞或显卡变化；重命名桌面文件按新增 / 删除处理。
